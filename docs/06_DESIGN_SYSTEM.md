Purpose:

This document defines Discora's visual language, component standards, UX principles, interaction patterns, and design consistency rules.

Discora should feel modern, elegant, welcoming, discussion-oriented, and knowledge-focused.

---

# 1. Design Philosophy

Discora is not:

* A traditional forum
* A social media clone
* An academic research platform

Discora is:

* A modern discussion platform
* A structured debate platform
* A knowledge-building platform

The design should encourage:

* Reading
* Participation
* Critical thinking
* Healthy discussion

without overwhelming users.

---

# 2. Visual Personality

Discora should feel:

* Modern
* Elegant
* Clean
* Professional
* Community-Oriented
* Knowledge-Focused

Inspiration:

Linear
+

Reddit

# 3. Core Design Principles

## Familiar First

Users should immediately understand:

* Posting
* Replying
* Discussing
* Debating

without tutorials.

---

## Structure Without Complexity

Discora organizes information without making users feel like they are filling forms.

---

## Readability Over Decoration

Information clarity is more important than visual effects.

---

## Discussion First

The conversation should always remain the primary focus.

---

## Mobile First

Every major experience should work comfortably on mobile devices.

# 23. Future Design Systems

Reserved for:

* Consensus Views
* Current Understanding Views
* Open Questions
* Knowledge Graphs
* Topic Hubs
* Argument Maps

These systems should extend the existing design language rather than introducing new visual paradigms.

---

# Final Design Goal

Discora should feel like a place where people want to think, discuss, learn, disagree respectfully, and build understanding together.

The design should reduce noise, improve clarity, and make structured discourse feel natural rather than academic.
